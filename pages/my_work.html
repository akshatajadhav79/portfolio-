Project 01

DB Chatbot — Natural Language to SQL

MongoDB

An AI-powered full-stack chatbot that converts plain English questions into executable MySQL queries. Features include voice-to-SQL input, real-time dashboard with live DB stats, JWT authentication, Undo/Rollback for write operations, and SQL caching for performance. The LLM backend uses Groq (Llama3-8b) via a FastAPI service with a React frontend.

LLM: Groq Llama3-8b
Backend: FastAPI + Python
Frontend: React + Vite
Database: MySQL + SQLAlchemy
Auth: JWT + bcrypt
Voice: Web Speech API

RAG

Project 03

AI Resume Analyzer & Job Matcher

LLM + AI

A tool that parses uploaded PDF resumes using PyPDF, extracts key skills and experience, then uses an LLM to compare against a job description and provide a match score, gap analysis, and rewrite suggestions. Built with FastAPI backend, React frontend, and Groq API for NLP processing.

LLM: Groq API (Llama3)
Parsing: PyPDF + LangChain
Backend: FastAPI
Frontend: React
Feature: Gap Analysis
Status: In Progress

Project 04

Ollama Local LLM Experiments

Local AI

Exploration of running open-source LLMs locally using Ollama — including Mistral, Llama2, and CodeLlama. Runtime: Ollama
Models: Llama2, Mistral, CodeLlama
Framework: LangChain
API: FastAPI
Focus: Privacy / On-Premise
Language: Python
